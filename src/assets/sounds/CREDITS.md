# Ambient sound credits

Every recording below is from Freesound and released under Creative Commons 0
(public domain), so no attribution is required. The sources are listed anyway
so each loop can be traced and rebuilt.

Each season has two loops: `-day` plays with the light theme, `-night` with the
dark theme. Each file was trimmed, mixed where it has two layers, matched in
loudness (day -23 LUFS, night -25 LUFS so evenings are a little calmer) and
encoded as 128 kbps stereo MP3. The player crossfades each pass into the next,
so the files don't need to loop on their own.
